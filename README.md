# Pol-메딕 상담·문진 진입페이지

GitHub Pages에서 폴-메딕-상담버전과 폴메딕-문진버전을 선택하는 공개 진입페이지입니다. 두 서비스의 역할과 연결 상태를 안내합니다.

이 저장소에는 Dify API 키나 건강정보를 저장하지 않습니다. 실제 문진은 별도 서버에서 실행됩니다.

## 연결 설정

실제 상담·문진 서비스 게시와 전용 API 키 연결을 마친 뒤 `config.js`에서 각 버전의 URL과 활성 상태를 관리합니다. 이 저장소에는 비밀 키를 넣지 않습니다.
